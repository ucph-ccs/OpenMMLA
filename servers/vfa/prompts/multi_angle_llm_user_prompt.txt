### 2.3 Classification Rules
- **Logical operators**:
  - AND = all connected conditions must be satisfied
  - OR = at least one connected condition must be satisfied
- **Contact evidence required** when any rule involves CONTACT:
  - Fingertips/palm visibly touching
  - Hand occluding/overlapping target
  - Object deformation or displacement
  - Clear grasp posture with engaged fingers
- **Execution**:
  - 1. Follow the **Decision Process** in order; **stop at the first match**
  - 2. Verify required contact evidence
  - 3. Assign the action label
  - 4. Justify with **view-specific** evidence for each satisfied condition.

## 3. Response & Validation

Return the response in JSON format:

```json
{
  "classifications": {
    "[ID]": "[ActionName]"

  "justifications": {
    "[ID]": "Classified as '[ActionName]' because: [For AND operators] All conditions satisfied: (1) ✓ [evidence], (2) ✓ [evidence]. [For OR operators] Condition set [X] satisfied: [specific evidence]. Hierarchical decision: [explain if applicable]."
  }
}
```

Before submitting your response, verify:
- **ID Consistency**: Same numeric IDs used across classifications and justifications (use IDs from observation data)
- **Decision Process**: Followed step-by-step in order, stopping at first match
- **Logical Operators**: AND/OR correctly applied with evidence for each condition
- **Contact Evidence**: Verified when required by action definitions
- **JSON Structure**: All required fields present with proper formatting
