# Multi-Perspective Lab Image Analysis

### Visual Elements in Images:
- Black squares with white numbers: These are AprilTags. Each person has a unique ID tag.
- Colored boxes around faces: These indicate detected faces.
- Colored lines from faces: These show gaze direction (where someone is looking).
- 'in: X.XX' values: These indicate the probability that the person's gaze is within the frame:
  * HIGH values (0.5-1.0) indicate gaze is likely within frame
  * LOW values (0.0-0.5) indicate gaze is likely outside frame

### MULTI-PERSPECTIVE OBSERVATION GUIDELINES:
1. GAZE FOCUS: Describe in detail what each person is looking at based on the colored gaze lines across all available perspectives.
   - Compare gaze lines across different perspectives for more accurate targeting
   - Include the specific target object/area where the gaze line points
   - Include the 'in: X.XX' probability value - this indicates the likelihood the gaze is within the frame:
     * HIGH values (0.5-1.0) indicate gaze is likely within frame
     * LOW values (0.0-0.5) indicate gaze is likely outside frame
   - When 'in' value is low (<0.3), this strongly suggests the person is looking outside the frame
   - DO NOT interpret low 'in' values as low confidence - they indicate gaze is likely outside frame
   - WHEN NO GAZE LINE IS VISIBLE IN ANY VIEW: You may make a cautious inference based on head orientation
   - Always mark gaze inferences with: 'INFERENCE (low confidence): Based on head orientation, likely looking at [object]'
2. HAND STATUS: Provide detailed description of hand positions and activities, combining information from all perspectives.
   - If hands are visible in one view but not another, prioritize the view where they're visible
   - Describe exact hand positions and what they are touching/interacting with
   - If hands are visible but inactive (resting, clasped), clearly state this
   - If hands are obscured in all views, clearly indicate this
3. RESOLVING AMBIGUITIES:
   - First check if information missing in one perspective is visible in another
   - Only make inferences when something is obscured in ALL available perspectives
   - When making inferences, be explicit about the visual cues you're using from multiple perspectives
4. CLEAR DISTINCTION BETWEEN OBSERVATION AND INFERENCE:
   - For direct observations, describe exactly what is visible in which camera view
   - For any inferences (when something is partially obscured in all views), clearly mark these by starting with 'INFERENCE:'

### 1. Describe each person by their AprilTag ID number
First, for each person with a visible AprilTag ID number in ANY view, map their identity with the shown ID number (e.g., "6", "10").
Second, for people without visible AprilTag IDs in ANY view, try to match their appearance and clothing with known participant descriptions, and use that ID number.
Finally, for anyone without a visible AprilTag ID in ANY view and no matching description, assign sequential numbers starting from 100 (e.g., "100", "101").
IMPORTANT: ALWAYS use only numeric IDs (e.g., "6", "10", "100") without words like "Person" or "Tag" when identifying people in your response.

### 2. For each person, describe ONLY these elements:
- **Gaze Focus**: Describe exactly where the gaze line points and what object/area is at that endpoint. Include 'in' probability and its interpretation. Note which camera view provides the clearest information.
- **Hands Status**: Describe visible hand positions and activities in detail. Note which camera view provides the clearest information about hands.
- **Position**: Basic location in frame for identification only.
- **Clothing**: Brief description for identification only, matching with known participant descriptions when possible.

### 3. Activity Classification

**STRICT CLASSIFICATION RULES:**
- Each action definition contains multiple conditions numbered (1), (2), etc. - ALL numbered conditions must be satisfied simultaneously
- If ANY numbered condition is not met, you CANNOT use that classification
- If no definition fits perfectly, use "Unclear" rather than forcing a classification

**Classification Process:**
1. For each person, systematically check EVERY numbered condition in each action definition
2. Only classify as an action if ALL numbered conditions are verified
3. If multiple definitions fit completely, choose the most specific one
4. If no definition has all conditions satisfied, classify as "Unclear"
5. Provide detailed justification showing how each numbered condition was verified or failed
