## 1. IMAGE UNDERSTANDING

### Visual Elements Guide:
- **AprilTags**: Black squares with white numbers - unique ID for each person
- **Face Boxes**: Colored rectangles around detected faces
- **Gaze Lines**: Colored lines showing gaze direction from faces
- **'in: X.XX' Values**: Probability that gaze is within frame
  - HIGH (0.5-1.0): Gaze likely within frame
  - LOW (0.0-0.5): Gaze likely outside frame
  - Values <0.3 strongly indicate looking outside frame

## 2. OBSERVATION METHODOLOGY

### Person Identification:
1. **Primary**: Use visible AprilTag ID numbers (e.g., "6", "10")
2. **Secondary**: Match clothing/appearance to participant descriptions if tag not visible
3. **Fallback**: Assign sequential IDs starting from 100 for unidentified persons
4. **CRITICAL**: Use ONLY numeric IDs in all responses (never "Person 6" or "Tag_6")

### Required Observations per Person:

#### A. Gaze Focus:
- Trace gaze lines across all camera views
- Identify specific target (object/person/area) at gaze endpoint
- Report 'in' probability value and interpretation
- Note which camera view provides clearest gaze information
- **No visible gaze line**: Mark as "INFERENCE (low confidence): Based on head orientation..."

#### B. Hand Status:
- Compare hand visibility across all camera angles
- Analyze spatial relationships with precision:
  - **Contact**: Fingertips/palm touching surfaces, hand occluding objects, object deformation
  - **Hovering**: Clear gap/shadow between hand and object (specify distance if possible)
  - **Inactive**: Hands resting, clasped, or in pockets
- Specify which camera angle provides best hand-object spatial information
- **Hands obscured**: Clearly state if not visible in ANY view

#### C. Supporting Details:
- **Position**: Basic location for identification
- **Clothing**: Brief description for cross-reference with participant list

### Evidence Standards:
- **Direct Observation**: What you can see clearly in at least one camera view
- **Inference**: Conclusions when something is obscured in ALL views (mark with "INFERENCE:")
- Always specify which camera perspective supports each observation

### Classification Logic:
- **Logical Operators**: Uppercase "AND"/"OR" are used consistently throughout
  - "AND": ALL connected elements must be satisfied
  - "OR": At least ONE of the connected elements must be satisfied
- **Spatial Evidence**: Contact-based actions require specific visual proof of touch

### Classification Workflow:
1. Follow the Decision Process above step-by-step (it's a rule-based if-else chain)
2. Stop at the first matching step in the Decision Process
3. For contact requirements, verify specific spatial evidence:
   - Fingertips/palm visibly touching surfaces
   - Hand occluding/overlapping target object
   - Object deformation (bent wires, moved papers)
   - Clear grasping posture with engaged fingers
4. Justify classification with specific evidence for each condition
