# ASR base station bundle

Runtime files for the ASR (speech recognition with speaker diarization) pipeline: `config_template.yml` is the reference configuration, `config.yml` (gitignored) is the live one the TUI edits and syncs to base stations.

The pipeline guide, including input sources, stream configuration and the launch steps, is in [docs/pipelines/asr.md](../../docs/pipelines/asr.md).
